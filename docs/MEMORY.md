# 记忆

## 机制

记的是**原句**，不是概括。检索单位是句子，装进上下文时按相关性排序、按预算装满。

```
写入    每轮对话按角色入库；带情绪快照（效价/唤醒）与时间
切事    按话题/停顿/长度把连续消息切成事件，事件是记忆的组织单位
检索    句子级：向量相似度取候选 → 精排 → 按分数装满预算
过期    带时间的事实到期自动失效（“下周三去医院”过周三即不再成立）
冲突    同一件事有两种说法时并列标注，不覆盖、不删除
```

## 你能看到什么

```
相关记忆按相关度排在前面，而不是按时间
块长度接近配置的 inject_chars（默认 14000）
情绪一致：高兴时更容易想起高兴的事
过期的事实不会以肯定语气出现
```

## 边界

```
不做跨会话自动归纳    每个会话独立，不推断“这个人整体是怎样”
不做摘要替代原文      溢出的句子会折叠，但保留“已折叠 N 条”而不是换写成一段话
精排只在候选内生效    预算装不下全部候选时才有意义；预算远大于候选时它只影响顺序
```
