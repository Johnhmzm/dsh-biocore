# 人设

## 机制

角色卡**编译一次**成数值，之后按数字运行，不每轮重新解释文字。

```
角色卡 → 特质（易怒/黏人/敏感…）→ 情绪基线：她默认停在哪个位置
       → 驱力权重：多需要社交、多怕被丢下
       → 表达参数：话多话少、语气软硬
       → 学习率：多容易被经历改变
```

编译结果存成预设，可以逐会话应用或覆盖。

## 你能看到什么

```
同一个角色，换一种问法不会突然变性格
重复加载同一份卡，行为不漂移
换卡之后，基线与表达风格随之改变，但历史记忆保留
```

## 边界

```
不解析每轮提示词    只在编译时读一次卡；改了卡需要重新编译
不覆盖状态          预设给的是起点与倾向，实际状态仍由经历决定
```
