# 关系

## 机制

关系是**状态量**，不是设定。它由互动累积，反过来影响语气与主动性。

```
信任      被认真回应时上升，被敷衍或冲突时下降
亲密      稳定互动累积；长时间断联会缓慢回落
依恋风格  焦虑/回避两轴，决定“被冷落”时的反应：追问、退开、还是稳住
```

更新用的仍是模型对每次交流的判断——不是「聊了多少句」这种计数。

## 你能看到什么

```
同一句话，关系近时更放松（句子长一点、愿意多说）
关系紧张时更客气、更短，主动性下降
被冷落后不会立刻归零，也不会无限累积——有上下界
```

## 边界

```
不做人格评判      只维护数值，不推断“你是什么样的人”
不替代记忆        关系是趋势量，具体发生过什么仍由记忆回答
```
