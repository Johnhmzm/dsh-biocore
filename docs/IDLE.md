# 不对话的时候

## 机制

没有消息时她不会停住。时间会推进状态，也会发生两件事：

```
回想   抽一条记忆重放一遍，按「近期 × 显著」加权
       重放会像当初那样推动状态，并少量挪动基线
走神   按当前状态生成一句内心话（想说 / 不想说），只记录，不说出口
```

频率按空闲时长累积，不按对话轮次。

## 为什么这样设计

| 机制 | 依据 |
| --- | --- |
| 离线重放 | 海马在休息与睡眠中重放近期经历（Wilson & McNaughton 1994；Foster & Wilson 2006 发现反向重放偏好近期），这是巩固而非噪声 |
| 自发思维 | 任务空缺时默认网络活跃、出现走神（Raichle 2001；Mason et al. 2007） |
| 必须有修复 | 只有负面重放而无修复，就是反刍（Nolen-Hoeksema 1991）——情绪会一路沉下去 |

第三条是实测出来的：只回放负面记忆 48 轮，效价会压到 -0.94。加上基线松弛后才回到 -0.34。
所以「慢慢往回漂」不是可选项，是防反刍的必要条件。

## 你能看到什么

```
长时间无人说话后，状态与基线会与断开时不同
记忆条数不变，但重放次数与内心话会累积（mindbase_idle.json）
负面经历多时，基线会被拉低但不至于卡死在底部
```

## 边界

```
不产生对话    内心话只记录，不会自己发出去
不无限重放    每次空闲最多几条，避免反复回放同一件事
不替代巩固    只做重放与走神，不做摘要重写，也不合并记忆
```
