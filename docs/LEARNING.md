# 学习

## 机制

三层，用的都是**同一个信号**：模型对每次交流的打分（-1…+1）。

```
谁打分    模型读完“对方说的”和“她回的”，判这一来一回接住没有
          例：“接住了陪伴与在意” +0.85；“没接住情绪，偏说教” -0.70

策略层    情境（停顿时相|依恋|时段）× 动作（接近/分享/提问/退开/修复/休息）的 Q 表
          回合内读：学出“这时别主动”就不发消息
          回合末写：被回应记正分；半小时无人理会记负分

关联层    什么线索预示什么结果，写入联想权重（稀疏编码 + 预测误差）

身体层    每轮微调一个旋钮（自发性幅度），幅度 3%，只沿适应度上升的方向
```

## 你能看到什么

```
该时段该情境下的主动性会变——被忽略几次后，她不再频繁发起
同一句话在不同日子得到不同对待，行为随之调整
没有重训、没有批量跑，边聊边变
```

## 边界

```
样本很少     一天几轮，策略表收敛很慢；这也是为什么身体层用爬山而不是搜索
打分有噪声   同一句话两次判分可能差 0.1–0.2，所以只取趋势，不追单次
不学内容     学的是“什么时候、用哪种方式”，不学“说什么”
```
