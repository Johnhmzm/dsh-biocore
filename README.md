# dsh-biocore

给对话智能体装一副**身体**：情绪、驱力、关系都是会自己变化的数值，而不是每次重新描述的角色设定。

模型是大脑，负责理解与措辞；这里是身体，负责状态、惯性与学习。两者之间只有一层：**向下把语言变成数字，向上把数字变成一句话**。

设计参考数字果蝇等生物模型；实现上只保留结构，不复制生物细节。

---

## 一、它解决什么问题

普通记忆插件能让模型「查到」过去，但查不到这三样：

```
她此刻是什么状态          没有人记录，每轮从零开始
这个状态从哪来            没有历史，只有一条条平铺的消息
它如何影响下一句话        状态不参与决策，只参与描述
```

结果就是：同一个角色，昨天被骂过和没被骂过，今天说话一模一样。**这不是记性问题，是身体缺失。**

---

## 二、机制

**输入 → 评价**：模型先给七维（目标、归因、可控、确定、新奇、涉入、受击），再导出合意度与可能性。回顾性情绪走阈值，前瞻性情绪走两者相乘；公平、施为、调节、应对、期望五个分量以**约束**形式进入，不与主项相加。

**情绪身体**：效价、唤醒、支配、紧张、社交五个连续量，由噪声驱动、随时间演化。三个尺度的慢层同时存在：

| 慢层 | 时间尺度 | 作用 |
| --- | --- | --- |
| 心 | 约 10 分钟 | 一次互动留下的余温 |
| 欠账 | 按负荷累积、按时间衰减 | 连续被消耗时的底噪 |
| 心境 | 约 4 小时 | 一整天的基调，与"这一刻"分开 |

**七套系统**：探索、照料、玩闹、亲密、恐惧、愤怒、分离，是从稀疏编码上读出的强度，不是标签。

**蘑菇体**：约 2000 个投射神经元，每个接 7 个输入（8% 掩码）；20 类多巴胺按预测误差改写权重；15 个隔间分别读出效价，再汇总成一句"心里"。

**记忆**：句子 → 命题（20–35 字，主语必须出现）→ 事件 → 日总结，四层各有写入条件。召回按向量与字面混合排序、按预算装填；事实会过期，冲突并列而不覆盖；原文永远不改写。

**决策**：阈值加噪声决定开不开口，打断成本与风险闸决定该不该说；说完之后做一次反向注入——她自己的话会改写自身状态一次。

---

## 三、能做什么

| 能力 | 一句话 |
| --- | --- |
| 情绪 | 五维连续量 + 七套系统，被话语推动、被经历改写，决定语气与长短 |
| 记忆 | 原文存储、命题压缩、事件归档；按相关度装填，冲突并列 |
| 学习 | 模型给每次交流打分，策略与联结权重据此调整，边聊边变 |
| 关系 | 信任与亲密是状态量，随互动变化，反过来影响语气与主动性 |
| 人设 | 角色卡编译成数值，不每轮重新解释文字 |
| 涌现 | 正负反馈配平时，她会收敛出"惯常的样子" |

## 四、安装

推荐插件市场安装；市场会同时写好加载清单，装完重启即可。

命令行安装只把包放进 `node_modules`，还要把包名加进 profile 的 `dsh.profile.bundles`，否则插件不报错也不出现（`/api/biocore/*` 全部 404）。

```bash
dsh plugin --profile web add dsh-biocore
```

重启后启动日志出现 `__bioWorker started` 即加载成功；`/api/biocore/stats` 返回 200 为正常（`available:false, reason:no_session` 表示还没进会话）。

---

## 五、边界

- 数据只落在本地 profile 目录，不联网、不上传；原文只存不改。
- 未做到的：她能否决主动消息，但不能自己发起；承诺识别样本少，多数停在中间值；旧条目没有情绪快照，一致性召回只对新记忆生效；连续数天的漂移尚未观测。

## 七、0.6.x 有什么不同

人设只在开场注入一次；记忆不再自动塞进提示词（改由 memory 工具按需调用）；长短由提示词判断而不是数字上限；新增反向注入（可关）。逐条开关见升级说明。

## 八、环境要求

DSH `>=0.2.0 <0.3.0`，Node `>=22`，需要 `web` 档（插件依赖 `webServer`）；纯 headless 档不会加载。

## 九、旧数据

不需要迁移：新旧会话目录命名都能读，缺新文件时走默认，不删旧文件、不改目录名。
