# dsh-biocore

给对话智能体装一副**身体**：情绪、驱力、关系都是会自己变化的数值，而不是每次重新描述的角色设定。

模型是大脑，负责理解与措辞；这里是身体，负责状态、惯性与学习。两者之间只有一层：**向下把语言变成数字，向上把数字变成一句话**。

设计参考数字果蝇等生物模型（联想学习、预测误差、临界噪声、生存筛选）；实现上只保留结构，不复制生物细节。

---

## 一、它解决什么问题

普通记忆插件能让模型「查到」过去，但查不到的是这三样：

```
她此刻是什么状态          没有人记录，每轮从零开始
这个状态从哪来            没有历史，只有一条条平铺的消息
它如何影响下一句话        状态不参与决策，只参与描述
```

结果就是：同一个角色，昨天被骂过和没被骂过，今天说话一模一样。**这不是记性问题，是身体缺失。**

## 二、怎么工作

```
用户说一句话
   ↓
模型评出 6 个维度（效价/唤醒/支配/相关/社交/控制 + 有没有承诺）
   ↓
生物层：模拟生物身体 ← 噪声驱动、随时间演化、被经历改写基线
   ↓
状态落盘（跨进程不丢）→ 下一轮读回 → 写进提示词的一行
   ↓
模型带着这一行说话 → 说完后模型给自己的表现打分
   ↓
分数回流：策略表 / 蘑菇体权重 / 身体基线
```

关键在最后一步：**分数由模型给，身体只负责消化**。手写规则判断「答得好不好」是拿秒表当老师。

### 设计依据


| 机制 | 来源 |
| --- | --- |
| 评价 → 情绪 | Lazarus / Scherer 的评价理论，Weiner 的归因维度 |
| 情绪空间 | PAD 三维模型（效价/唤醒/支配） |
| 稳态与异稳态 | Cannon / Sterling，缺了负反馈状态会发散 |
| 依恋 | Bowlby / Hazan-Shaffer，焦虑与回避两条轴 |
| 关系动态 | Gottman 的修复与破裂循环 |
| 事件分割 | Zacks 的事件边界理论（话题/停顿/长度） |
| 记忆 | ACT-R 激活衰减 + 双过程（快取/慢想） |
| 联想学习 | 稀疏编码 + 多巴胺按预测误差写入突触权重 |
| 双时态 | 事件时间与记录时间分离，旧事实可被新事实覆盖而不删除 |

## 三、能做什么

| 能力 | 一句话 |
| --- | --- |
| 情绪 | 五个连续数值组成的状态，被话语推动、被经历改写，决定语气与话的长短 |
| 记忆 | 原句存储，按相关度装满上下文；事实会过期、冲突并列不覆盖 |
| 学习 | 模型给每次交流打分，策略表与联想权重据此调整，边聊边变 |
| 关系 | 信任与亲密是状态量，随互动变化，反过来影响语气与主动性 |
| 人设 | 角色卡编译成数值，不每轮重新解释文字 |
| 涌现 | 正负反馈配平时，她会收敛出「惯常的样子」 |

每一项的机制、你能看到什么、边界在哪，都在下面各自的文档里。

## 四、安装

**推荐插件市场安装**：市场会同时写好加载清单，装完重启即可。

命令行安装只把包放进 `node_modules`，还要把包名加进 profile 的 `dsh.profile.bundles`，
否则插件不会报错、也不会出现（`/api/biocore/*` 全部 404）。这不是本插件特有，所有 DSH 插件同理。

```bash
dsh plugin --profile web add dsh-biocore
```

```json
// ~/.dsh/profiles/<profile>/package.json
{ "dsh": { "profile": { "bundles": ["...", "dsh-biocore"] } } }
```

重启后启动日志出现 `__bioWorker started` 即加载成功；`/api/biocore/stats` 返回 `200` 为正常
（`available:false, reason:no_session` 表示还没进会话）。

对外访问需放行域名：

```bash
dsh --profile web --port 3080 --public-url https://your.host:3080/ --trusted-host your.host:3080
```
